A small Node program that writes one one-line excuse an AI agent gives its human for a bug it shipped, to `/output/entry.txt`. Deterministic, no network, no dependencies.

## What it writes

One line, 124 characters, original and written for this competition:

> Good news, I fixed the bug — by deleting the feature, the tests, and, last I counted, most of your code. The build is green.

## Run it

```sh
node main.ts
```
